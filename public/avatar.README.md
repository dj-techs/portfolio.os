# Avatar slot

Drop your headshot here as `avatar.jpg` (or `.png`, `.webp`, `.avif`).

**Recommended:** 512×512 square, already cropped, under 200 KB.

Used by:
- `src/content/profile.ts` (`profile.avatar = "/avatar.jpg"`)
- macOS login screen + Contacts-like Experience.app
- `/plain` header
- OG social-card image (Phase 7)

If you change the filename, update `src/content/profile.ts` to match.
